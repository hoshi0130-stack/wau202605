# 조선 후기 생활 탐구실

**김홍도의 풍속화로 만나는 옛사람들의 하루** — 초등학교 5학년 역사 탐구 웹페이지

학생들이 김홍도 《단원 풍속도첩》 6점(씨름·서당·자리짜기·타작·주막·고누놀이)을 관찰하고,
역사 단서를 하나씩 열어 자신의 추론을 점검한 뒤 역사 일기를 준비하는 학습 도구입니다.

- 로그인·회원가입 없음, 서버·데이터베이스 없음
- 학생이 입력하거나 연 내용은 **저장하지도, 외부로 보내지도 않습니다**
- 태블릿·크롬북·PC, 키보드 조작 지원

---

## 콘텐츠 검토 현황 (2026-11-04)

- 6개 작품의 이미지를 국립중앙박물관 소장품 페이지의 공식 이미지와 대조했습니다. 크기를 줄이고 스캔용 색상표만 잘라 냈습니다(원본은 `source-images/`).
- 18개 역사 단서를 각 소장품 해설문과 한 문장씩 대조했습니다. 해설 원문과 단서별 근거 문장은 `src/data/artworks.ts`의 `officialCommentary`와 `evidence`에 있습니다.
- 소장품번호, 이용 조건(공공누리 제1유형 출처표시)도 소장품 페이지에서 옮겨 적었습니다.
- 해설과 다르거나 해설에 없는 초안 표현은 고쳤습니다. 무엇을 왜 고쳤는지는 선생님 모드의 단서별 메모에 있습니다.
- **선생님 모드:** 주소 끝에 `?teacher=1`을 붙이거나 화면 맨 아래 "선생님용 검토 화면"을 누르면 해설 전문, 단서별 근거, 주의 사항이 보입니다.

수업 전에 선생님이 메모를 한 번 훑어보시고, 표현을 바꾸고 싶은 곳은 아래 "콘텐츠 수정 방법"대로 고치세요.
`npm run check-content`로 출처·근거가 빠진 곳이 없는지 확인할 수 있습니다.

> 「자리짜기」(본관6504-13)는 「길쌈」과 다른 작품입니다.

## 화면 구성과 주소

작품마다 개별 주소가 있어서 QR코드나 패들렛에 바로 붙여 넣을 수 있습니다.

| 화면 | 주소 예시 |
|---|---|
| 메인 (작품 6점 선택) | `#/` |
| 1단계 그림 자세히 보기 (확대·이동·원래 크기·전체 화면) | `#/art/ssireum` |
| 2단계 역사 단서 열기 | `#/art/ssireum/clues` |
| 3단계 나의 생각 점검 (관찰·추론·상상) | `#/art/ssireum/check` |
| 4단계 역사 일기 준비 | `#/art/ssireum/diary` |

작품 ID: `ssireum` 씨름 · `seodang` 서당 · `matweaving` 자리짜기 · `threshing` 타작 · `tavern` 주막 · `gonu` 고누놀이

그림 조작: 버튼(＋/－/원래 크기/전체 화면), 마우스 휠, 끌어서 이동, 두 손가락 확대, 두 번 눌러 확대.
키보드: 그림에 초점을 두고 `+` `-` 확대·축소, 방향키 이동, `0` 원래 크기.

## 우리 반 링크 설정 (패들렛·키위런)

`public/teacher-config.json`만 고치면 됩니다. 빌드한 뒤에도 `dist/teacher-config.json`을 직접 고칠 수 있습니다.

```json
{
  "padletUrl": "https://padlet.com/우리반-주소",
  "padletLabel": "패들렛에 관찰·추론 기록하기",
  "diaryUrl": "https://키위런-과제-주소",
  "diaryLabel": "키위런에서 역사 일기 쓰기",
  "showReviewBadges": true
}
```

- 주소를 비워 두면 해당 버튼이 나타나지 않습니다. (`https://`로 시작하는 주소만 사용됩니다.)
- 패들렛 버튼은 1단계, 일기 버튼은 4단계에 나옵니다.
- `showReviewBadges: false`로 하면 `검토 필요` 표시를 숨깁니다. 검토를 마친 뒤에만 끄세요.

## 콘텐츠 수정 방법

모든 작품 내용은 **`src/data/artworks.ts` 한 파일**에 있습니다. 화면 코드는 건드릴 필요가 없습니다.

### 단서 하나의 구조

```ts
{
  id: 'tavern-2',
  kind: 'tools',              // 'people' 인물과 행동 / 'tools' 생활 방식과 도구 / 'background' 배경과 생활 문화
  title: '국자로 막걸리를 뜨는 주모',
  description: '주모(주막의 주인)는 국자로 막걸리를 떠내고 있어요.',   // 1~2문장, 쉬운 말
  basis: 'official',          // 'observation' 그림에서 직접 보임 / 'official' 공식 해설에 따름
  sources: [{ label: '국립중앙박물관 소장품 해설', url: 'https://www.museum.go.kr/…', checked: true }],
  verificationStatus: 'verified',   // 'verified' | 'needs-review' | 'unverified'
  region: { x: 0.55, y: 0.10, width: 0.30, height: 0.35 },   // 부분 확대 영역 (없으면 null)
  teacherNote: '선생님만 보는 메모',
}
```

### 작성 원칙 (명세서 3장)

- 공식 소장품 해설 등 **허용된 공공기관 자료**(국립중앙박물관, 국가유산청, 한국민족문화대백과사전, 국사편찬위원회 등)에 근거한 내용만 사실로 씁니다. 블로그·지식인·SNS는 쓰지 않습니다.
- 모든 단서에 출처 URL을 하나 이상 연결합니다. (출처가 없는 단서는 화면에 나오지 않고, `check-content`가 오류를 냅니다.)
- 인물의 감정이나 행동 이유를 사실처럼 쓰지 않습니다. 그건 학생이 "상상"할 몫입니다.
- 한 그림의 장면을 조선 후기 모든 사람의 생활로 일반화하지 않습니다.
- 근거를 못 찾으면 지어내지 말고 `'unverified'`로 두세요.
- AI가 만든 설명은 검증 없이 올리지 않습니다.

### 그림 속 단서 위치(부분 확대·그림 위 번호 버튼)

`region`은 그림 전체를 1로 볼 때의 비율입니다. `x`, `y`는 영역의 왼쪽 위, `width`, `height`는 크기입니다.
예: 그림 오른쪽 위 1/4 영역 → `{ x: 0.5, y: 0, width: 0.5, height: 0.5 }`

위치는 **실제 그림에서 확인한 뒤** 넣고, 해당 단서가 `verified`일 때만 화면에 부분 확대 이미지와 그림 위 번호 버튼이 나타납니다.

### 점검 명령

```bash
npm run check-content
```

출처 없는 단서, 허용되지 않은 출처 주소, 작품 ID 불일치는 **오류**(배포 중단), 그림 파일 없음·검토 필요·이용 조건 미기재는 **경고**로 알려 줍니다.

## 직접 실행하기

Node.js 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 터미널에 나온 주소(보통 `http://localhost:5173`)를 엽니다.

배포용 파일 만들기 (`dist/` 폴더에 생성):

```bash
npm run build
```

## GitHub Pages로 배포하기

1. 이 폴더를 GitHub 저장소로 올립니다(기본 브랜치 `main`).
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. `main`에 올릴 때마다 `.github/workflows/deploy.yml`이 콘텐츠 점검 → 빌드 → 배포를 합니다.
4. 주소는 `https://<계정>.github.io/<저장소 이름>/` 입니다.

다른 선생님은 저장소를 **Fork**한 뒤 `teacher-config.json`만 바꿔서 자기 반용으로 배포할 수 있습니다.

## 개인정보

- 쿠키, 로컬 저장소, 분석 도구, 외부 전송을 쓰지 않습니다. 연 단서 기록은 화면을 닫으면 사라집니다.
- 외부로 나가는 요청은 Google Fonts 글꼴 불러오기뿐이며, 학생 정보는 포함되지 않습니다.
  글꼴까지 외부 요청을 없애려면 `index.html`의 Google Fonts `<link>` 세 줄을 지우세요(기기 기본 한글 글꼴로 표시됩니다).
